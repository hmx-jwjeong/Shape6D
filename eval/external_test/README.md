## 해석 (04 팔레트 결과와의 대조가 곧 교훈)

1. **찾으면 정밀하다**: 성공 시 3.5mm/0.62° — 20cm급 가정용 물체·희소화 조건에서도 스펙급.
2. **34%의 모호 실패 = 기하 단독의 본질 한계**: 뒷면이 가려진 얇은 상자류에서 뒤집힌/90° 포즈가
   가시면에 완벽 정합. 팔레트에서 플립을 잡던 두 장치(직립 뷰 프리이어·"바닥 관측 앞 침범"
   free-space)가 임의 자세 탁상 물체엔 부재 → **M1(RGB prior)·M2(coarse 강건화 학습)의
   존재 이유가 외부 데이터로 정량 실증됨.**
3. **검증기 도메인 이전 실패(오수락 40%)**: 팔레트+바닥 맥락에서 완벽했던 물리 증거 verdict가
   가려진-뒷면 클러터에선 플립을 분리 못함 — M3-3 보정 셋에 이 데이터 유형 필수,
   05 간과점 6-A(오포즈 카탈로그)·3-1(보정 도메인)의 실증.
4. **모드 B 5% = S1 기하 클러스터의 클러터 한계 실증** (접촉 물체 병합→크기 게이트 소실) —
   05 간과점 #7, M1 EViT-SAM 마스크 경로의 근거.
