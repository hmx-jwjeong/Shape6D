3빨강 5건 — 교체 결정

3.1 인코더 초기화: FB 가중치 → timm/convnext_tiny.in12k_ft_in1k

문제
FB 공식 저장소가 명시한다 — 코드는 MIT지만 ImageNet 사전학습 가중치는 CC-BY-NC. 상업 제품의 초기화로 쓰면 위반이다.
[검증 완료] 13·14 파일럿의 timm 기본 pretrained=True가 어느 태그로 해석됐는지 실측 확인한 결과, 설치된 timm 1.0.27의 기본 태그는 in12k_ft_in1k(Apache-2.0)였다 — 즉 파일럿은 우연히도 깨끗한 가중치를 썼고 산출물 오염은 없다. 다만 timm 버전에 따라 기본 태그가 바뀔 수 있으므로 명시 고정이 필수다.
교체
timm/convnext_tiny.in12k_ft_in1k — Apache-2.0, timm 프로젝트가 자체 학습한 IN-12k→IN-1k 체크포인트 (모델카드 license 필드 직접 확인). 구조가 동일하므로 12 §7.1의 절단·예산 계산이 그대로 적용된다. Phase A 코드에 체크포인트 태그를 명시 고정하고 fb_* 태그를 금지한다. 스크래치 대조군은 라이선스 무풍 폴백으로 유지(측정 격차 작음 — 13 §4.2b).

3.2 매칭 디코더: SAM-6D 코드 포팅 → 클린룸 재구현

문제 — 이번 실사에서 가장 무거운 발견
SAM-6D 저장소에는 LICENSE 파일이 없다. 오픈소스처럼 보이지만 법적으로는 all rights reserved다. 그런데 03 정본은 pose_estimation_model.py 라인 번호까지 참조하며 "M2에서 포팅"을 전제해 왔다(README 구조도의 shape6d/pose 주석 포함). 코드를 보고 옮기는 순간 파생물이 된다. 외부 교사(유사도행렬) 옵션도 같은 이유로 불가.
교체
① 클린룸 재구현 — CVPR 2024 논문(공개 문헌)과 우리 설계 문서(03 §6.5 — 이미 구조를 자체 언어로 재기술해 둠)만으로 구현한다. 구현자는 SAM-6D 소스를 열지 않는 것을 규약으로 명문화. 참조 수치(6000/300, nsample 등)는 논문 기재 값이라 사용 가능.
② 교사는 자체 full-size PEM만 (M2-D 자기 증류 — 원래 1차안이라 계획 변경 없음).
③ M0-1(SAM-6D BOP 재현)은 U3 사내 평가라 저위험이나, 저자에게 라이선스 문의 이슈를 남기는 것을 권장(응답 시 옵션 복원 가능).

3.3 S2 디스크립터: GeDi 증류 → 자체 대조학습

문제
GeDi 저장소도 LICENSE가 없다. 교사 가중치 자체를 쓸 수 없으므로 "GeDi → PointNet-lite 증류"(18 §2.2)가 성립하지 않는다.
교체 — 오히려 더 깨끗한 경로가 있다
자체 대조학습 디스크립터. MegaPose-GSO에는 GT 포즈가 있으므로 점 대응 라벨을 무한 생성할 수 있다 — 같은 물체의 서로 다른 부분 뷰에서 대응점을 양성, 비대응·타물체 점을 음성으로 하는 InfoNCE로 PointNet-lite(0.35M)를 직접 학습한다. GeDi의 방법론(LRF·다중 스케일)은 논문 참조(U4)로 차용 가능. 교사가 없어졌을 뿐 데이터·구조·예산은 동일하고, 산출물의 권리가 완전히 우리 것이 된다. 비용: Phase C 증류 1런 → 대조학습 1런 (동급).

3.4 RGB 교사 ablation: CroCo v2 제외

CC BY-NC-SA 확인 — 증류 학생이 NC-SA에 오염될 위험이 있어 교사 후보에서 제외한다. 17 D-4는 "기각"으로 종결. 남는 팔: DINOv3 ViT-L(약관 조건부) vs 증류 생략(스크래치 MBConv 유지). Co-op이 시사한 "대응 사전학습이 낫다" 가설은 아쉽지만, 애초에 RGB branch는 보조(0.4M)라 손실 폭이 제한적이다.

3.5 S1 백업: EdgeSAM → MobileSAM

EdgeSAM은 S-Lab NC 1.0(비상업 명시)이라 백업 목록에서 제외. MobileSAM(MIT)이 동급 경량 대체재로 확인됐다. 기본안 EfficientViT-SAM(Apache-2.0)은 그대로.

4노랑 — 조건부 사용과 그레이존

항목쟁점운용 방침
DINOv3 License상업 사용은 허용 명시. 쟁점은 두 조항: ① 재배포 시 동일 약관 동봉 + "Built with DINOv3" 표시 ② 파생물도 동일 약관 — S2에 동결 ViT-S를 실으면 제품이 이 의무를 진다. 교사로 쓰면 증류 학생이 파생물인지가 해석 문제S2 탑재·교사 채용 모두 법무 검토 통과를 조건으로(D-2). 통과 전 기본 경로는 DINOv2-S(Apache) + 증류 생략. 통과 시 표시 의무를 제품 고지에 반영
SAM License (SAM 3)연구·상업 허용 custom — 군사/ITAR 사용 제한·재라이선스 금지. 우리 용도는 사내 도구(U3)라 재배포 없음. 잔여 쟁점: SAM 3가 생성한 주석의 지위(평가셋에 포함되어 외부 공개될 경우)내부 사용 진행 가능. 주석 공개 전 약관 확인. 군수 전용 제한은 UAM(도심항공) 전시 문맥과 무관하나 최종 고객 용도 확인 항목으로 기재
ImageNet 계열 일반론timm 체크포인트가 Apache여도 ImageNet 데이터 자체의 약관(연구 목적)이 가중치에 미치는지는 업계 미해결 그레이존 — 관행상 수용되나 판례 없음잔여 리스크로 문서화. 스크래치 대조군이 상시 폴백이므로 프로젝트가 인질이 되지 않음. Phase A에서 격차가 작게 나오면(13에서 +0.024) 스크래치 기본화로 완전 해소 가능
SA-1B ↔ EfficientViT-SAMSA-1B 데이터는 연구 약관이지만 우리는 데이터를 쓰지 않고 Apache-2.0 가중치만 쓴다 — 가중치 라이선스가 준거저위험 수용. 자체 재학습 금지(데이터 약관 회피 목적)
