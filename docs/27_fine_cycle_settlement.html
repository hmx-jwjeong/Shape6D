② g* 비정합 발견: 학습에서 fine 조건화 좌표는 R_gt 기준, CE 라벨은 대칭 정준화된 R_eff=R_gt·g* 기준인데 g*≠I 비율 85% — 샘플 대다수에서 좌표 프라이어가 라벨과 대칭회전만큼 어긋남. 헤드가 "좌표는 못 믿는다"를 정확히 학습했고, 이것이 PE 무효(v2)의 근본 원인. v3는 fine점 기준 select_g_star로 초기 포즈를 R_gt·g* 프레임에서 생성해 정합.

발산 사고 기록 (재발 방지)
v3 1차 기동은 1스텝 발산(연속 skip 300): λ30 게이트가 원거리 행 전경 로짓을 −수백까지 눌러 soft solve 대응 가중이 0으로 붕괴 → 공분산 H≈0 퇴화 → SVD backward NaN → 파라미터 오염. forward 가드(가중합 1e-8 클램프)로는 backward 경로를 못 막는다. 수정: 게이트 페널티 상한 30 클램프 + fine 손실에서 soft solve 포즈 항 제거(CE 전용 — eval이 hard solve라 목적 정합, NaN 경로 동시 제거).
