v0.1 · 2026-07-18 · 전제 문서: 01_stage_design.html (권장 구성 승인됨) · 인력 가정: 개발 1~2명 · 기간 추정은 그 기준

0. 확정 스택과 목표 지표

스테이지확정 구성 (01 문서 권장안)
S0 온보딩Poisson disk + 노멀 · depth 템플릿 42뷰 · 대칭 자동검출 · 오브젝트 측 텐서 전량 캐시
S1 제안EfficientViT-SAM-L0 (depth 전경 포인트 프롬프트) + depth 클러스터링 병렬 → 합집합 NMS
S2 판별크기 게이팅 → depth 템플릿 정합(주 신호) → DINOv2 ViT-S 의미 점수(약한 prior) · appearance 점수 제거
S3 포즈Shape6D-PEM: SAM-6D 매칭 구조 승계 + 기하 주도 인코더 + RGB 보조 branch(modality dropout) + CAD 직접 온보딩 + top-k 가설
S4 정련·검증depth 렌더 잔차로 가설 선별 → point-to-plane ICP(robust kernel) → 보정 신뢰도 accept/reject (대칭군 등가 평가)

목표 지표 (전 구간 공통 게이트)

지표목표측정
정확도 — BOP-Classic-Core unseen AR≥ 67 (SAM-6D 70.4 − 3pt 이내)BOP 공식 툴킷, 특히 T-LESS·ITODD 개별 추적
강건성 — 재도장 프로토콜 AR 낙폭≤ 3pt (SAM-6D는 대폭 하락 예상 — 실측으로 확인)자체 오염·재도장 증강 프로토콜 (M0에서 구축)
속도 — Jetson Orin NX end-to-end< 1s (내부 목표 600ms)스테이지별 프로파일러, MAXN 및 15W 모드 각각
신뢰도 — 오수락률 (false accept)< 1% @ 리콜 손실 ≤ 5%S4 accept/reject ROC (M3에서 구축)
D1. 대상 보드 — 확정: 타깃은 Orin NX, 단 당분간 실기 테스트 없음. 개발·검증은 로컬(Ubuntu·Blackwell GPU PC)에서 수행하고, Jetson 실기 프로파일링은 보드 확보 시점에 M4 전제조건으로 이월. 그 전까지 레이턴시 게이트는 로컬 실측 + 공개 벤치 기반 환산 계수로 운용(M0-2).
D2. 센서 — 확정: depth는 LiDAR로 리파인하며, LiDAR 포인트가 존재하는 지점만 사용 → 유효 기하가 "밀집·노이즈"가 아니라 희소·고정밀로 이동. S1 병렬 경로·S2 정합 방식·M2 증강 설계를 이에 맞게 수정(본문 반영). 잔여 확인 D2-a: LiDAR 기종·작업 거리에서 물체 위 유효 포인트 수 — S3 입력 설계(npoint)와 성능 하한을 결정하는 수치.
D3. 학습 GPU — 확정: Blackwell 워크스테이션급 1장 보유(Ubuntu PC). 파일럿(M2-B) + 본학습 1회(M2-C) + 압축(M2-D)은 1장으로 실행 가능하나, 전체 스윕(E2·E4)은 서브셋 한정으로 제한. 본학습 1회가 병목이 되면 해당 런만 클라우드 버스트 옵션. 잔여 확인 D3-a: 정확한 GPU 모델·VRAM("H600"은 존재하지 않는 모델명 — RTX PRO 6000 Blackwell 96GB로 추정) 및 PC의 CPU 코어·RAM·NVMe (PBR 데이터 로딩이 실질 병목이 되는 경우가 많음).

개발 전략 3원칙

① 항상 동작하는 파이프라인 유지 — 빅뱅 재작성 금지. SAM-6D를 기준선으로 두고 스테이지 단위로 교체하며, 매 교체마다 BOP 회귀를 돌린다. ② 학습 없는 개선을 먼저 — M1에서 캐싱·모델 교체·게이팅만으로 얻는 이득을 확정한 뒤, 재학습(M2)은 "남은 갭"에만 투입. ③ 측정이 결정한다 — 인코더 선정·경량화 폭·가설 수 등 모든 아키텍처 결정은 M0에서 만든 평가 하네스의 수치로 결정.

M2-B. 인코더 파일럿 — 3후보 통제 비교 (2주)

동일 조건(학습 데이터 10% 서브셋, 동일 매칭부·loss·스케줄)에서 3후보를 소규모 학습해 수치로 선정한다:

후보구성가설탈락 조건
(a) image-grid conv (우선순위 1)depth→XYZ+노멀+결측마스크를 2D 격자 그대로 경량 conv 백본에 입력, RGB 보조 branch concatTRT 직행·최속. 정확도가 (b)와 동급이면 즉시 채택crop 내 심한 깊이 불연속에서 2D 이웃 근사 붕괴 시
(b) PointNet++ liteSA 2단, 노멀 포함. FPS→voxel 다운샘플, kNN→radius 해시 그리드로 커스텀 op 제거 버전기하 표현력 기준점(a) 대비 정확도 이득 < 1pt인데 레이턴시 2배 이상
(c) sparse convspconv 계열표현력 상한 확인용TRT/Jetson 배포 경로가 기한 내 확보 안 되면 즉시 제외 (배포성이 1급 기준)

공통 설계: 장면 측(2.5D 부분 관측)과 CAD 측(완전 3D 포인트)의 도메인 차이 → 인코더 가중치는 공유하되 도메인 플래그 임베딩을 추가하는 안을 기본으로 하고, 파일럿에서 분리 인코더와 비교. D2 확정 반영: 장면 측 포인트는 희소(수백 pt 가능성)이므로 파일럿 평가 데이터에 희소 패턴을 반드시 포함하고, 가변 포인트 수 내성을 선정 기준에 추가 — (a) grid conv는 유효포인트 마스크 채널로 희소성을 처리하되, 희소율이 높을수록 (b) 포인트 직접 처리 계열이 유리해질 수 있어 D2-a 수치가 사실상 인코더 선정의 캐스팅보트다.
