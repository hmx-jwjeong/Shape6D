v1.0 · 2026-07-30 · 상위 문서: 17(v3 라인·Phase 계획) — 본 문서는 그 구성요소 조달 명세다 · 실측 근거: 13·14·15 · UAM = 평가 전용(17 §5.5) 전제 하에 작성
요약 v3 파이프라인의 학습 가능 슬롯은 5개뿐이다 — S3 기하 인코더·RGB 보조·매칭 디코더(SGD), S2 기하 디스크립터(증류), S4 보정기(로지스틱 적합). 나머지는 전부 동결 NN이거나 비학습 알고리즘이며, 이것이 이 설계의 특징이다(학습 실패가 파이프라인 전체를 무너뜨리지 않는다).

사전학습 결정의 원칙은 셋이다: ① 온라인 슬롯에는 사전학습을 "직접 탑재"하지 않고 초기화·증류로만 유입시킨다(예산 실측 근거). ② 태스크 학습 데이터는 MegaPose-GSO + 센서 스펙 합성 희소화 단일 계보로 통일한다(UAM 배제). ③ 라이선스가 미확정인 자산(DINOv3·SAM 3·ShapeNet)은 전부 폴백이 있는 보조 경로에만 둔다 — 기본 경로는 Apache/MIT급 자산만으로 성립한다.

2.4 S3 RGB 보조 branch

스크래치 MBConv 0.4M로 시작한다 — 이 크기에 유효한 사전학습 가중치가 없고, modality dropout(p=0.3)이 있어 초기 성능 의존도가 낮다. Phase C에서 교사 증류 A/B: DINOv3 ViT-L(시각 일반) vs CroCo v2(크로스뷰 대응 — Co-op이 DINO 대신 택한 계보, 대응 태스크 적합 가설). 증류 데이터는 MegaPose 렌더의 RGB 뷰 — 추가 수집 불요.

2.5 S3 매칭 디코더 — 사전학습이 존재하지 않는 슬롯

구조가 신규(H=192·2블록·1024pt)라 직접 얹을 사전학습 가중치가 없다. SAM-6D 공개 가중치(H=256·3블록·2048pt)는 차원이 달라 직접 초기화 불가. 조달 경로는 두 가지다:
① 본학습 (Phase B) — MegaPose-GSO에서 g* 대칭 손실로 스크래치 학습. 이것이 주 경로.
② 자기 증류 (Phase C, M2-D) — 03 정본이 규정한 경로: full-size(H=192·필요시 3블록)로 본학습한 자체 교사의 유사도행렬을 축소판(H=128·2블록·1024pt)에 정렬. 256-d 유사도 공간을 유지한 이유가 이 정렬이다. 각 1/3 스케줄, 총 ~5일.
외부 교사 옵션: SAM-6D PEM(MegaPose 2M 사전학습, 공개 가중치)의 유사도행렬 정렬 — 단 RGB 주도 특징이라 A1과 상충하는 성분이 섞인다. Phase C ablation의 한 팔로만 두고 기본은 자체 교사. 가중치 라이선스 확인 필요.

이 흐름의 성질
① 새로 수집해야 할 학습 데이터가 없다 — 전 Phase가 디스크의 MegaPose-GSO와 합성 생성물로 돌아간다. 수급 리스크는 학습이 아니라 평가 보조(BOP 다운로드)와 다양성 확장(D4)에만 있다.
② 라이선스 최악 시나리오에도 기본 경로가 성립한다 — DINOv3·SAM 3·ShapeNet·ImageNet 가중치가 전부 불가로 판명돼도, 남는 구성(스크래치 인코더 + GSO 학습 + DINOv2-S 보조 + 자체 교사 증류)으로 파이프라인 전체가 완성된다. 잃는 것은 성능 후보이지 기능이 아니다.
③ UAM은 세 지점에서만 등장한다 — Phase A/B 게이트 평가, 보정기 홀드아웃, (평가 주석 강화). 전부 읽기 전용이다.
