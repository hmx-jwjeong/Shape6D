1.4d 운용 스펙 확정 반영 — 상시 3m · 커버 2~5m · 회전 ≤1° (2026-07-18 사용자 확인)

"기종 선택이 중요하지 않은가"에 대한 답: 브랜드는 중요하지 않다. 그러나 각도 분해능은 물체 위 포인트 수 N을 고정하고, N이 위치·회전 정밀도의 물리적 하한(σ/√N, σ/(√N·r))과 S2/S4 임계 전부를 결정한다 — 이 스펙(상시 3m, 회전 1°)에서는 ML-X(80)과 ML-A(60)의 분해능 차이 1.8×가 정확히 성패 경계선 위에 있다. ML-X를 쓴다면 반드시 ML-X(80)이어야 하며(ML-X(120)은 명백 미달), 아래 매트릭스처럼 실질 결정 변수는 기종이 아니라 부품 크기다.

@dataclass
class FrameBundle:
    rgb: np.ndarray            # [800,1280,3] u8, undistorted
    lidar_points: np.ndarray   # [N,3] f32, 카메라 좌표계 (T_cam_lidar 적용 완료)
    lidar_intensity: np.ndarray# [N] f32
    lidar_t_offset: np.ndarray # [N] f32 (deskew 확장용 보존, v1 미사용)
    lidar_pixels: np.ndarray   # [N,2] f32 서브픽셀 (u,v); 이미지 밖 = NaN
    sparse_depth: np.ndarray   # [800,1280] f32 z-buffer, 0=무효
    valid_mask: np.ndarray     # [800,1280] bool
    pix2pt: np.ndarray         # [800,1280] i32 픽셀→포인트 인덱스, -1=무효
    point_quality: np.ndarray  # [N] u8 플래그 OR (0=클린)
    K: CameraIntrinsics        # fx,fy,cx,cy (+dist=0)
    T_cam_lidar: np.ndarray    # [4,4] f64 (기록용)
    t_rgb: float; t_lidar: tuple; meta: dict

# 소비 규약
# S1: valid_mask(전경 프롬프트) + lidar_points/pixels(클러스터 경로, NaN uv 사전 필터)
# S2: 마스크 2~3px erosion 후 pts = lidar_points[pix2pt[eroded_mask & valid_mask]], quality==0 우선
# S3: 동일 추출 + quality 비트를 유효마스크 채널에 반영
# S4: ICP 대응은 EDGE_MIXED 제외 기본, 잔차 검증은 sparse_depth 대비

품질 플래그 산출: EDGE_MIXED = 반경 3px 내 이웃 유효픽셀과 깊이차 > 3cm(빔 풋프린트 mixed pixel 의심), LOW_INTENSITY = 반사 강도 하위 임계, NEAR_MASK_BOUNDARY = S1 이후 마스크 경계 2~3px 이내(RGB 특징 신뢰도 하향에 사용). 마스크 2~3px erosion 후 포인트 선별이 전 스테이지 표준 절차 — 캘리브레이션 2px 오차 + 빔 풋프린트 5mm가 겹치는 경계 밴드에서 배경 포인트(cm~수십cm 오차) 혼입을 차단.

5S2 후보 판별 — 3단 캐스케이드

SAM-6D ISM의 (semantic + appe + geo·vis)/(2+vis)에서 appearance 완전 제거, semantic은 ViT-S로 축소·강등, geometric(bbox IoU)은 메트릭 신호로 교체. 판별의 주 신호가 GEO로 이동한다. 캐스케이드가 무료 신호를 앞에 둬서 descriptor forward 횟수(=구 ISM 레이턴시 주범) 자체를 줄인다.

5.1 ① 크기 게이팅 (무료)

P_j = pts(eroded mask, quality==0 우선)                    # §2.2 표준 절차
d_obs = ‖percentile(P_j, 95) − percentile(P_j, 5)‖ (축별 트리밍 bbox 대각)
통과 ⇔ β_occ·D_cad ≤ d_obs ≤ (1+τ_up)·D_cad  AND  N_j ≥ 30
  τ_up = 0.15 (관측이 물체보다 커질 물리적 이유 없음 — 타이트)
  β_occ = 0.35, 가림 정황(경계 절단 or 전방 마스크 겹침) 시 0.25로 완화
S_size = clamp(d_obs / D_cad, 0, 1)

5.2 ② point-to-template 정합 (주 판별 신호) — 수정판

검증 [상-2]·[상-3] 반영 — 초안 결함 2건 수정: ① 시선축 정렬: 관측 포인트를 카메라 z축 기준으로 in-plane 탐색하면 화면 주변부 물체(최대 35° 오프센터)에서 정합이 붕괴 — TDF 조회 전 centroid 시선 → z 정렬 회전(Rodrigues 1회)으로 뷰잉-레이 프레임에 옮긴다(템플릿 렌더 규약과 정합). ② 탐색 격자 강화: 42뷰(커버 반각 17.8°) × in-plane 30°의 합성 최악 오차 ≈ 23° → 주변부 포인트 변위 0.2D = τ_trunc의 2배로 정답 점수 붕괴 위험. pass2를 상위 3뷰 × in-plane 15° 재탐색 + jitter ±2 voxel로 확장. M2 착수 전 정답 포즈 주입 스모크 테스트(S_depth 분포 확인)를 필수 게이트로.
# 정규화: 스케일 정규화 금지(메트릭이 판별 신호), 병진 = median 센터링 (vs tpl_center)
# 가속: 뷰별 TDF voxel LUT (48³, voxel 0.025D, τ_trunc 0.1D) — O(1) gather, KD-tree 불가(A4)
q_i = R_z(θ) · R_align(ray→z) · (p_i − median(P_j))
s(j,v,θ) = mean_i max(0, 1 − tdf[v][voxel(q_i)] / τ_trunc)
S_depth(j) = max over (v∈42, θ∈12@30°) → pass2: top3 뷰 × θ∈24@15° × jitter δ∈{−2..2}³ 부분탐색
# 단방향(관측→템플릿)인 이유: 가림 불변. 부작용(파편 정합)은 ①크기 게이팅이 차단
# 복잡도: ~25M fp16 gather (M'=8, P=1000) → 데스크톱 ~3ms / Orin ~15ms (추정)

5.3 ③ DINOv2 ViT-S 의미 점수 (약한 prior) + ④ 융합

crop: bbox 정사각 1.25× 확장 → 마스크 밖 ImageNet mean 치환 → 224² (템플릿 렌더와 동일 도메인)
S_sem = mean(top5(cos(cls, dino_cls[42])))            # ②의 S_depth ≥ 0.3 생존 후보만 forward
S2 = 0.6·S_depth + 0.2·S_size + 0.2·S_sem             # M0-3 프로토콜로 튜닝 (E6)

7.1 가설 선별 — 투영 스플랫 잔차 (렌더링 없음)

입력 명세(검증 [M5] 반영): 인스턴스당 가설 3개 — hyp0 = fine 정련품, hyp1..2 = coarse 원본. 대칭 등가 dedupe(canonicalize 후 geodesic 15° & Δt 0.05D 병합) 시 fine품이 항상 생존 우선. UNCERTAIN 재시도로 coarse 가설에서 ICP를 시작할 때는 iter 10→15, τ_assoc 2배로 수렴 반경 보상.

S0 idx_verify 2048pt를 가설 포즈로 투영 → stride-2 그리드 scatter-amin z-buffer → 3×3 min-pool(스플랫 구멍 메움)
→ 관측 LiDAR 유효 픽셀에서만 gather → r = obs_z − z_model
score = mean(relu(1−|r|/τ_z)) · coverage^γ,  τ_z = 3σ_lidar
r > +τ_z = free-space 위반(모델이 관측 앞) → 오포즈의 강한 증거 (별도 집계)
r < −τ_z = 가림/오염 퇴적 가능 → 관대

7.2 Projective point-to-plane ICP

검증 [중-5] 반영 — 대응 탐색 창을 상수 3×3으로 두면 측방 도달이 ±3.3mm@1m뿐이라 coarse 오차 1cm에서 대응이 안 잡혀 no-op 수렴한다. win = ceil(τ_assoc·fx/(Z·stride))로 유도(1m·τ_assoc 20mm·stride 2 → win≈9)하거나 stride 8→2 coarse-to-fine 2단으로 구현.
방향: source = 관측 LiDAR(희소·EDGE_MIXED 제외), target = 포즈 적용 CAD 마스터 16384pt
노멀: CAD 측(S0 캐시) — 희소 관측에서 노멀 추정 불가·CAD 노멀은 정확 무료
대응: projective association (scatter-amin 셀 그리드 + win×win 이웃 3D 최근접) — kNN/KD-tree 없음
iter 5~10: Huber(δ=1.5σ_lidar) 가중 p2pl 잔차 → J=[(q×n)ᵀ,nᵀ] → 6×6 정규방정식 → SE(3) 좌측 갱신
수렴: ‖ω‖<1e-4 rad & ‖ν‖<0.05mm, 또는 잔차 감소율 <1e-3
퇴화: cond(H) = λ_min/λ_max < 1e-6 → degenerate 플래그 (평면 조각 등 6DoF 미구속 → ACCEPT 금지)

7.3 신뢰도 보정 + 대칭 등가 + 판정

특징 10-d: [inlier_ratio, rmse_inlier/τ_z, coverage, free_viol, S2_depth, S2_sem,
            s3_match, log10(N_obs), log10(cond_H), border_flag] → 로지스틱 → p_conf
캘리브레이션: BOP val(T-LESS·ITODD 우선) + M0-3 오염 프로토콜, 라벨 = 대칭 인식 오차(MSSD/MSPD 준용)
  — 오염 셋 필수 포함: "오염이지만 정답" 표본이 양성으로 학습되어야 reject 경계가 올바름
판정: 하드 가드(inlier<25 → ACCEPT 금지 / degenerate → 금지 / free_viol>0.05 → REJECT)
  → p_conf ≥ 0.7 ACCEPT / 0.3~0.7 UNCERTAIN(차순위 가설 재시도 1회 → 재촬영 신호) / <0.3 REJECT

오염 대응 4겹: ① Huber+inlier 한정 통계 — "정답+국소 오염"(inlier_ratio↓, rmse 정상)과 "오포즈"(둘 다 나쁨)가 특징 공간에서 분리 ② MAD 적응 임계(상한 2τ_z 캡) ③ 부호 비대칭 — 퇴적은 r<0 방향이므로 관대, free-space 위반(r>+τ)만 hard ④ 캘리브레이션 셋에 오염 포함. 대칭: sym_rots/sym_axes(§2.4 정본)로 canonicalize(연속축은 swing-twist 제거) — 가설 dedupe와 라벨링 양쪽 적용, T-LESS 대칭군 오reject 0이 M3 게이트.
